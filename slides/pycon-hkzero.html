ARCHITECTURAL EVOLUTION // AWS GAME VS. KUBERNETES GAME

Why We Moved from AJAX to WebSocket + Lambda Durable Functions

Kubernetes Grading Evaluates Live Workloads & Container Lifecycles—Not Just Fast SDK Metadata

☁️ Previous AWS Game: Simple AJAX

  • Fast SDK Lookups: Grading AWS labs only needed control-plane reads (s3.get_bucket_policy, ec2.describe_instances).
  • Sub-Second Latency: boto3 API calls return in 100–800ms.
  • Synchronous HTTP Worked: Simple fetch('/task') request/response easily finished well under API Gateway limits.

💥 Why Kubernetes Broke AJAX

  • Real Workload Lifecycles: K8s tests must apply YAML, pull images, schedule Pods, wait for ReadinessProbes, and test live endpoints.
  • Chained Multi-Phase Runs: One trigger chains 01_setup + 02_ready or 04_challenge (chaos injection) + 05_check.
  • 29s HTTP Timeout Wall: Multi-phase pytest runs take 15–60+ seconds, hitting API Gateway's hard 504 Gateway Timeout!

⚡ New: WS + Durable Functions

  • Instant Async Hand-Off: game-ws-handler validates & queues the job via InvocationType="Event" in <100ms.
  • No 29s Ceiling: @durable_execution runs long multi-phase pytest suites reliably with checkpointed state.
  • Live Phase Streaming: Pushes real-time phase updates (_push_game_update) + ETA estimates before the final callback!
The Core Difference: In an AWS game, grading is a 200ms SDK metadata read (boto3). In a Kubernetes game, grading is a 15–120s real-world chaos & reconciliation test against live containers!

Why Decouple Step 2 & Step 3?
API Gateway WebSockets have a strict 29-second integration timeout, and rapid monster kills can flood the backend. Fast ingestion + async durable execution solves both!
Zero Polling Required:
The browser never polls an HTTP endpoint. Python pushes real-time state transitions (RUNNING → COMPLETED) directly back down the open WebSocket connection.

NEW SERVERLESS PRIMITIVE // AWS LAMBDA DURABLE FUNCTIONS

What is AWS Lambda Durable Functions & Features We Use

Stateful Checkpoint-and-Replay Workflows in Pure Python — Without Step Functions ASL YAML

⚡ What is a Lambda Durable Function?

  • Pure Python Workflows: Build long-running, stateful orchestrations using aws_durable_execution_sdk_python directly inside Lambda.
  • Checkpoint & Replay Engine: Each context.step() call checkpoints its return value. On retry or resume, completed steps replay from history without re-running side effects!
  • 1-Hour Execution Window: Supports ExecutionTimeout: 3600 (1 hr) and RetentionPeriodInDays: 14 for built-in execution audit logs.

🛠️ 4 Key Features We Use in k8s-grader-api

  • 1. DurableConfig + :live Alias: SAM auto-publishes a versioned :live alias required for deterministic durable replay.
  • 2. @durable_execution Entrypoint: Injects DurableContext into lambda_handler to manage step state.
  • 3. @durable_step Checkpointing: Wraps execute_game_command_step so multi-phase K8s grading runs as an atomic step.
  • 4. Guaranteed Lock Release: try / finally ensures execution_guard_repo.release() always unlocks the student session.

  Type: AWS::Serverless::Function

@durable_step
def execute_game_command_step(step_context, action, email, game, npc, endpoint, conn_id):
    return execute_game_command(action, email, game, npc, endpoint, conn_id)

@durable_execution
def lambda_handler(event: Dict[str, Any], context: DurableContext) -> Dict[str, Any]:
    try:
        payload = context.step(
            execute_game_command_step(action, email, game, npc, endpoint, conn_id)
        )
    finally:
        execution_guard_repo.release(execution_guard_key)  # Always unlock!
    _push_game_update(endpoint, conn_id, action, payload)

PYTHON DEEP DIVE // STAGE 4: PYTEST AS A GRADING MICROSERVICE

Running pytest Programmatically Inside AWS Lambda

🧪 Why pytest is the Ultimate Grader

  • Fail-Fast (-x): Stops at the first broken assertion so the game gets feedback in seconds.
  • Self-Contained Reports: --html=/tmp/report.html packages full tracebacks and cluster diffs into a single file.
  • Smart S3 Uploads: Reports are uploaded to S3 with presigned URLs only when tests fail, keeping passed checks blazingly fast.
  • Exit Code Mapping: Maps completed.returncode directly to our TestResult enum.
k8s-grader-api/common-layer/common/pytest.py TestRunner 
def run_tests(test_phase: GamePhrase, game: str, task: str, timeout=30) -> TestResult:
    get_tests(game)  # Download & cache test archive in /tmp/{game}
    try:
        completed = subprocess.run(
            [
                sys.executable, "-m", "pytest",
                f"--rootdir={get_root_path(game)}",
                "--import-mode=importlib",
                "--html=/tmp/report.html",
                "--self-contained-html",
                "-x",  # Stop on first failure for fast game UX
                f"{get_test_base_path(game)}/{game}/{task}/test_{MAPPING[test_phase]}.py",
            ],
            env=build_pytest_env(), timeout=timeout, check=False
        )
        return TestResult(completed.returncode)
    except subprocess.TimeoutExpired:
        return TestResult.TIME_OUT
PYTHON DEEP DIVE // STAGE 5: ASYNC WEBSOCKET CALLBACK

Closing the Loop with apigatewaymanagementapi

📡 Pushing Verdict to WebGL

  • Handling DynamoDB Decimals: Standard json.dumps() crashes on Decimal scores from DynamoDB; a custom DecimalEncoder converts them cleanly.
  • Direct Connection Push: Uses the student's connection_id and callback endpoint_url to push JSON directly to the browser.
  • Resilient Cleanup: Catches GoneException if the player closed their browser tab mid-check, and always releases the DynamoDB execution lock in finally.
k8s-grader-api/game-command-handler/app.py WS Callback 
class DecimalEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, Decimal):
            return int(obj) if obj % 1 == 0 else float(obj)
        return super().default(obj)

def _send_ws_message(endpoint: str, connection_id: str, payload: Dict[str, Any]):
    client = boto3.client("apigatewaymanagementapi", endpoint_url=endpoint)
    message = json.dumps(payload, cls=DecimalEncoder).encode("utf-8")
    try:
        client.post_to_connection(ConnectionId=connection_id, Data=message)
    except client.exceptions.GoneException:
        logger.info("Game websocket connection %s is gone", connection_id)
